# keyboard^2
This week I'm making a keyboard(the computer one) that works like a keyboard(The instrument).It has 49 keys, two buttons for Octave Up and down, A rechargeable battery and a speaker system.
## <ins>Reason for making it</ins>
I wanted to make a keyboard for this week, but when i looked up online I only saw tutorials on hot to make the tying kind of keyboard, and then I thought why not combine them both since they should functionally be the same if a speaker is added to the keyboard. This is also now doable on Kicad and allows me to have more resources to use while making said keyboard.
## <ins>How it works</ins>
The main chip used is a Raspberry Pro Pico 2, Its connected up to 49 keys set up in a matrix.The keys are in a 7x7 grid.There are an addiitonal 2 keys set up separately from the matrix to allow changing of octave. There is a speaker set up with an amplifier, speaker used is a Mini 8 ohm Speaker or a cavity speaker and the amplifier used is a Pam 8403.The battery used is a Lithium Ion Battery and is assisted by a TP4056 module.

## <ins>Features</ins>
- 49 Playable keys
- Rechargeable and portable
- Speakers that play 10Khz-37Khz
- The full catalogue of octaves
- If you know some coding, you can play any sound!!!!
